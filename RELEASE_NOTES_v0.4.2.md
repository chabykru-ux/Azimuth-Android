# Azimuth v0.4.2

First public GitHub release of Azimuth.

## What is Azimuth?

Azimuth is a free Android utility that adds a configurable edge slider for fast app access without replacing the normal Home screen.

## Highlights

- Favorites and custom categories
- Fast app launching from the edge
- App reordering inside categories
- Move apps between categories
- Left/right slider placement
- Adjustable slider position
- Permanent Settings entry
- Home-screen-only mode using Usage Access
- Three optional Azimuth wallpapers
- English, Russian and Hebrew support

## Tested on

- Google Pixel 10 Pro
- Samsung Galaxy Flip 8

## Download

Recommended:
- `Azimuth-v0.4.2-Android.zip`

The package includes:
- signed release APK
- three Azimuth wallpapers
- installation instructions in Russian and English
- SHA-256 checksums

## Installation notes

Azimuth requires **Display over other apps** permission for the slider.

If **Show slider: Home screen only** is enabled, Azimuth also requires **Usage Access**.

See the README and the included installation guide for details.
