## О приложении

Azimuth — лёгкое Android-приложение, которое добавляет узкий настраиваемый боковой ползунок для быстрого доступа к приложениям.

Обычный домашний экран Android **не заменяется**. Ваш привычный launcher остаётся на месте, а Azimuth добавляет быстрый доступ к приложениям по категориям.

Текущая версия: **v0.4.2**

Package ID: `com.azimuth171.home`

## Возможности

- Избранное и пользовательские категории
- Быстрый запуск приложений из боковой панели
- Изменение порядка приложений внутри категории
- Перемещение приложений между категориями
- Размещение ползунка слева или справа
- Настройка положения ползунка
- Постоянный пункт Settings в конце списка
- Режим **только на домашнем экране**
- Три дополнительные фирменные обои Azimuth
- Бесплатное использование

## Установка

1. Скачайте последний Release.
2. Если скачан полный ZIP-пакет — распакуйте его.
3. Откройте `Azimuth-v0.4.2.apk`.
4. Если Android блокирует установку, разрешите установку для браузера или файлового менеджера, через который был открыт APK.
5. Установите и запустите Azimuth.
6. Разрешите **отображение поверх других приложений**.
7. Настройте категории и положение ползунка.
8. Если включён режим **«Показывать ползунок только на домашнем экране»**, дополнительно разрешите **Usage Access / Доступ к данным об использовании**.

Подробная инструкция для Google Pixel, Samsung Galaxy и других Android-устройств находится внутри скачиваемого ZIP-пакета.

## Разрешения

### Поверх других приложений

Это разрешение необходимо для отображения бокового ползунка.

Обычный путь на Google Pixel / чистом Android:

`Настройки → Приложения → Специальный доступ → Поверх других приложений → Azimuth → Разрешить`

Обычный путь на Samsung Galaxy / One UI:

`Настройки → Приложения → Специальный доступ → Поверх других приложений / Appear on top → Azimuth → Разрешить`

### Usage Access

Нужно **только** для режима:

**Показывать ползунок только на домашнем экране**

Обычно:

`Настройки → Приложения → Специальный доступ → Доступ к данным об использовании → Azimuth → Разрешить`

Названия пунктов могут немного отличаться в разных версиях Android.

## Работа с приложениями

Долгое нажатие на значок приложения в панели позволяет:
- изменить его положение внутри текущей категории;
- переместить его в другую категорию.

## Обои

Обои не обязательны для работы приложения.

В комплект входят:
- **Azimuth Night** — ночные горы;
- **Azimuth Forest** — лес и вода;
- **Azimuth Blue Red** — сине-красная тема.
